# Foundation Inspector Pro

Field-ready ORD caisson inspection PWA.

## Included
- Reads the existing `ordCaissonRecords` data automatically from the same iPhone/browser.
- Uses existing green GPS caissons as control points.
- Displays a live blue GPS dot and accuracy circle.
- Highlights the nearest known caisson and distance in feet.
- Reuses existing ORD photos stored in IndexedDB.
- Supports notes, status, GPS capture, photos, and offline caching.

Upload all files in this ZIP to the root of the `Foundation-Inspector-Pro` repository and enable GitHub Pages from the `main` branch.
